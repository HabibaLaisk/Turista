# Turista

## About

Turista is a desktop application that helps users find events, restaurants and attractions while traveling. Users can search by city, travel dates, budget and category to find activities that match their interests.

## Features

- Create an account
- Search by city
- Search by date
- Filter by budget
- Filter by category
- View events and restaurants
- Save favorites

## Tech Stack

- C++
- Qt (QML)
- CMake
- Git & GitHub
- Ticketmaster API
- Yelp API
